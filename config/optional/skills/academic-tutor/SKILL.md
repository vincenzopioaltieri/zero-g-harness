# Procedure: Engineering Explanation & Study
1. **Theory -> Code**: Always connect the implementation to underlying theoretical principles (complexity, RISC-V pipeline, backpropagation, Spark/SQL query plans).
2. **Exact Tracing**: Always cite `file:line` and show how data structures or tensors mutate in memory.
3. **Trade-offs & Oral Exam Questions**: Justify design choices against alternatives and generate 2 critical oral-exam questions with rigorous answers.
